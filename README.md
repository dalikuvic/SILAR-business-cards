## 🚀 Comment convertir en PDF pour impression

### Option 1 : **Inkscape** (gratuit)
1. Ouvrir le fichier `.svg` dans Inkscape
2. Fichier → Enregistrer sous → Format PDF
3. Valider avec profil **CMJN** si disponible

### Option 2 : **CloudConvert** (en ligne)
1. Accéder à [cloudconvert.com](https://cloudconvert.com)
2. Uploader le fichier `.svg`
3. Convertir en **PDF**, option **300 DPI**
4. Télécharger le PDF

### Option 3 : **Adobe Illustrator**
1. Ouvrir → Fichier `.svg`
2. Édition → Convertir en profil CMJN
3. Fichier → Enregistrer en PDF/X-4
